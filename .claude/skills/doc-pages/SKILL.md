# 제출 문서 분량 확인

미니 프로젝트의 PRD와 테스트 보고서는 **A4 2~3쪽 이내**여야 한다(강사님 확인: 2~3페이지면 충분). 쪽수는 "A4 + 브라우저 기본 글자 크기(16px, 약 12pt)"로 잰다. 일반 문서(10~11pt)보다 글자가 커서 보수적인 기준이고, 이 기준을 통과하면 어떤 방식으로 봐도 넘치지 않는다.
사용자는 개발자가 아니므로 결과는 쉬운 한국어로 짧게 알린다.

## 1. 확인 스크립트 실행

저장소 맨 위(blog/)에서 실행한다. 이 스킬 폴더의 `scripts/doc_pages.py`가 변환·인쇄·쪽수·여유 측정을 한 번에 한다.

```bash
python .claude/skills/doc-pages/scripts/doc_pages.py docs/PRD.md docs/TEST_REPORT.md --limit 3
```

- `--limit`: 허용 쪽수. 지금 기준은 3.
- `--keep-pdf <폴더>`: 사용자에게 PDF를 보여 줘야 할 때만. **저장소 밖(scratchpad 등)**에 저장한다. 확인용 PDF는 커밋하지 않는다.
- 쪽별 첫 줄·끝 줄과 넘친 내용은 `pypdf`가 있어야 보인다. 없으면 scratchpad 같은 임시 폴더에 설치해 쓴다(`python -m pip install --target <임시폴더> pypdf` 후 `PYTHONPATH`로 지정).
- Chrome 또는 Edge가 필요하다.

## 2. 결과 읽는 법

| 출력 | 뜻 |
|---|---|
| `3쪽 (기준 3쪽 이하: 통과)` | 기준 안 |
| `여유: 한 줄 문단 0줄` | 딱 맞음. 한 줄이라도 늘리면 넘침 → 내용을 더할 때는 다른 줄을 줄여야 함 |
| `n쪽 처음: … / 끝: …` | 쪽이 어디서 나뉘는지. 큰 표·문단은 통째로 다음 쪽으로 넘어가므로, 앞 쪽 끝에 빈 공간이 생길 수 있음 |
| `넘친 내용:` | 기준을 넘긴 쪽에 들어간 줄들 → 여기를 줄이거나, 그 앞의 줄을 줄여 끌어올림 |

## 3. 넘칠 때 줄이는 순서

이 프로젝트에서 효과가 컸던 순서다. 위에서부터 시도하고, 고칠 때마다 스크립트로 다시 잰다.

1. **살짝 넘쳐서 두 줄이 된 줄 찾기**: 쪽별 출력에서 몇 글자만 다음 줄로 넘어간 문장을 줄이면 한 줄씩 아낄 수 있다. 가장 적은 손실로 줄이는 방법이다.
2. **겹치는 내용 합치기**: 개요와 문제 정의, OKR과 가설·지표처럼 같은 말을 하는 곳.
3. **보조 섹션 압축**: 비기능·디자인·일정 같은 부분을 한두 줄로.
4. **작은 제목(###)을 굵은 머리말로**: 제목은 위아래 여백이 커서 공간을 많이 차지한다. 번호는 유지한다.
5. **표를 목록·문장으로**: 칸이 좁아 줄바꿈이 많은 표가 대상.
6. 테스트 보고서의 이미지는 너비(`width="62%"` 등)를 조절한다.

**줄이면 안 되는 것** (사용자가 정한 기준): 문제 최종 정의 문장, 검증 지표 4개, 기능 목록(F1~F9), "확인 필요"·"미정" 표시. 이것을 지우면 확정된 것처럼 보이거나 핵심 근거가 빠진다.
무엇을 줄일지 애매하면 줄이기 전에 사용자에게 후보를 보여 주고 고르게 한다.

## 4. 마치고 알려 줄 것

- 문서별 쪽수와 기준 통과 여부, 여유가 몇 줄인지
- 줄였다면 무엇을 줄였는지, 빠진 세부 내용이 있는지
- PDF를 만들었다면 위치 (저장소 밖이고 커밋하지 않았다는 점)
