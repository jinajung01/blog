## 2. 개요
블로그에 학습과 경험을 정리하는 관리자(본인)는 강의 중에는 키워드 위주로 짧게 메모하고,
실습 중에는 기록하지 못한다. 시간이 지나면 맥락을 잃어 복습·포트폴리오에
활용하지 못한다. 관리자 전용 챗봇이 수업 메모·실습 내용을 받아 빠진 맥락만 짧게
묻고, 블로그 글 초안(제목·요약·본문·카테고리·태그)으로 정리해 저장까지 돕는다.

## 3. 문제
### 3.1 현황
- 블로그: GitHub Pages + Firebase(로그인·글 저장), GA 연결, 카테고리 기획/디자인/회고
- 정리 방식: 매 수업 작성하지만 교안에 없는 발언을 키워드 위주로 기록하고 일부만 설명함

### 3.2 문제 목록
| 문제 | 원인 | 결과 |
|---|---|---|
| 강의 메모가 짧게 남음 | 듣기와 기록을 동시에 해야 함 | 나중에 뜻을 알 수 없음 |
| 실습 기록이 없음 | 손이 실습에 묶여 기록 불가 | 다시 따라 할 수 없음 |
| 정리 단계 생략 | 핵심 선별·맥락 보충·형식 작성 부담 | 복습·포트폴리오로 활용 못 함 |

### 3.3 문제 검증 (본인 기록 점검)
지난 수업 글 (N편, 확인 필요)을 다시 읽고 측정
| 지표 | 정의 | 현재값 |
|---|---|---|
| 설명 기록률 | 설명이 붙은 키워드 ÷ 전체 키워드 | 확인 필요 |
| 맥락 유지율 | 지금 한 문장으로 설명 가능한 키워드 ÷ 전체 키워드 | 확인 필요 |
| 실습 기록률 | 실습 내용이 남은 회차 ÷ 실습한 회차 | 확인 필요 |
| 재현 가능률 | 지금 다시 따라 할 수 있는 실습 ÷ 전체 실습 | 확인 필요 |

### 3.4 문제 최종 정의
블로그에 수업을 정리하는 수강생(관리자 본인)은 강의 중에는 메모가 짧게 남고
실습 중에는 기록할 수 없어, 수업이 끝난 뒤 맥락을 잃거나 아예 남지 않은 내용을
복습과 포트폴리오에 활용하지 못한다.

## 4. 해결 방안
### 4.1 솔루션 정의
기억이 남아 있을 때 짧은 질문 몇 개로 빠진 맥락을 채워,
다시 읽어도 이해되는 블로그 글을 남기게 한다.

### 4.2 AS-IS / TO-BE
| 구분 | AS-IS | TO-BE |
|---|---|---|
| 강의 | 키워드 메모만 남음 | 설명 빠진 키워드만 질문 → 맥락이 담긴 글 |
| 실습 | 기록 없음 | 회상 질문(만든 것·순서·막힌 점·배운 점) → 실습 기록 |
| 형식 | 제목·요약·태그·카테고리 직접 작성 | 자동 초안 후 확인·수정 |
- 타깃: 관리자 본인 (복습 + 포트폴리오 목적)
- 비즈니스 모델: 해당 없음 (개인 도구, 무료 등급 내 운영)

### 4.3 예상 성과 (OKR)
- O: 수업이 끝나면 다시 읽어도 이해되는 기록이 남는다
- KR1: 맥락 유지율 3.3 현재값 대비 상승 (목표치는 점검 후 설정)
- KR2: 실습 기록률 3.3 현재값 대비 상승 (목표치는 점검 후 설정)
- KR3: 수업 1회 정리 소요 시간 단축 (현재값 확인 필요)

## 5. 가설 및 지표
| 가설 | 지표 |
|---|---|
| H1. 설명 없는 키워드만 질문하면 맥락 유지율이 오른다 | 맥락 유지율 |
| H2. 회상 질문을 주면 실습 기록이 남는다 | 실습 기록률 |
| H3. 형식을 자동 생성하면 정리 시간이 줄어든다 | 정리 소요 시간 (현재값 확인 필요) |
| H4. 자유 입력에서도 강의/실습을 구분할 수 있다 | 구분 정확도 (테스트) |
- 페르소나: AI PM 과정 수강생, 블로그 관리자 본인. 매 수업 정리하지만 키워드 위주
- 핵심 메시지(가안): "기억이 남아 있을 때, 질문 몇 개로 글을 완성"

## 6. 기능 요구사항
| ID | 기능 | 설명 |
|---|---|---|
| F1 | 관리자 전용 접근 | 로그인한 관리자에게만 챗봇 표시 |
| F2 | 자유 입력 | 강의 메모 / 실습 회상 / 섞인 입력을 모드 선택 없이 입력 |
| F3 | 입력 구분 | 강의·실습을 구분해 맞는 질문 선택 |
| F4 | 맥락 질문 | 설명이 빠진 부분만 짧게 질문 (최대 개수 확인 필요) |
| F5 | 질문 건너뛰기 | "그냥 써줘"로 바로 초안 생성 |
| F6 | 초안 생성 | 제목·요약·본문·태그 + 카테고리 추천(기획·디자인 중 내용에 맞게 1개) |
| F7 | 수정 요청 | "더 짧게" 등 대화로 초안 수정 |
| F8 | 저장 | 기존 글 저장 기능으로 블로그에 게시 |
- 미정: 섞인 입력의 결과를 한 글로 할지 여러 글로 할지 (확인 필요)
- 유즈케이스: 로그인 → 챗봇 열기 → 입력 → 질문 응답(또는 건너뛰기) → 초안 확인·수정 → 저장
