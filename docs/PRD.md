# PRD v1.0 — 수업 기록 → 블로그 초안 정리 챗봇

## 1. 기본 정보·개요
v1.0 완성본 · 2026-11-24 · 작성자 정지나 · 배포 https://jinajung01.github.io/blog/ (글쓰기 화면)
수업 메모·실습 내용을 받아 빠진 맥락을 묻고 블로그 글 초안으로 정리해 주는 관리자 전용 챗봇.

## 2. 문제
**2.1 현황** 수업 내용은 개인 노트에 키워드 위주로 적고 일부만 설명함. 블로그(기획/디자인/회고)에는 수업 정리 글이 없음.

**2.2 문제 목록** ① 강의 메모가 짧아 뜻을 잃음 ② 실습 중엔 기록 못 함 ③ 정리(선별·맥락·형식) 부담으로 건너뜀

**2.3 문제 검증** 지난 수업 개인 노트(N회분, 확인 필요)를 다시 읽고 측정. 현재값은 모두 확인 필요
- 설명 기록률 = 설명이 붙은 키워드 ÷ 전체 키워드 · 맥락 유지율 = 지금 한 문장으로 설명 가능한 키워드 ÷ 전체 키워드
- 실습 기록률 = 실습 내용이 남은 회차 ÷ 실습한 회차 · 재현 가능률 = 지금 다시 따라 할 수 있는 실습 ÷ 전체 실습

**2.4 문제 최종 정의** 수업을 정리하는 수강생(관리자 본인)은 강의 중에는 메모가 짧게 남고
실습 중에는 기록할 수 없어, 수업이 끝난 뒤 맥락을 잃거나 아예 남지 않은 내용을
복습과 포트폴리오에 활용하지 못한다.

## 3. 솔루션
**3.1 솔루션 정의** 기억이 남아 있을 때 짧은 질문 몇 개로 빠진 맥락을 채워, 다시 읽어도 이해되는 블로그 글을 남기게 한다.

**3.2 타깃** 블로그 관리자 본인(AI PM 과정 수강생). 수업 직후 기억이 남아 있을 때 복습·포트폴리오용 기록을 남기려는 사람. 비즈니스 모델 없음(개인 도구, 무료 등급).

**3.3 문제별 해결 (AS-IS → TO-BE)**
- ① 짧은 강의 메모 → 설명 없는 키워드만 골라 질문해, 수업에서 들은 맥락이 담긴 글
- ② 실습 미기록 → 회상 질문(만든 것·순서·막힌 점·배운 점)으로 실습 기록
- ③ 정리 부담 → 제목·요약·본문·카테고리·태그 자동 초안, 확인 후 기존 버튼으로 저장

## 4. 가설 및 지표 (OKR)
O: 수업이 끝나면 다시 읽어도 이해되는 기록이 남는다
- H1. 설명 없는 키워드만 질문하면 맥락 유지율이 오른다 → KR1 맥락 유지율 상승 (목표 확인 필요)
- H2. 회상 질문을 주면 실습 기록이 남는다 → KR2 실습 기록률 상승 (목표 확인 필요)
- H3. 형식을 자동 생성하면 정리 시간이 줄어든다 → KR3 수업 1회 정리 시간 단축 (현재값 확인 필요)
- H4. 자유 입력에서도 강의/실습을 구분할 수 있다 → 구분 정확도 (테스트)

## 5. 기능 요구사항
- F1 관리자 전용 접근: 관리자가 아니면 로그인 화면으로 이동, 챗봇은 관리자 확인 뒤에만 불러옴
- F2 자유 입력: 강의 / 실습 / 섞인 입력을 한 칸에. 섞인 입력도 글 1개(관련 없으면 '강의'·'실습' 소제목)
- F3 입력 구분: 강의·실습·섞인 입력을 구분해 맞는 질문 선택
- F4 맥락 질문: 설명 빠진 부분이 있으면 초안 전에 한 번에 최대 3개, 대화당 1회
- F5 질문 건너뛰기: 질문을 받은 뒤 "그냥 써줘" 버튼으로 바로 초안
- F6 초안 생성: 제목(40자 이내)·요약(1~2문장)·본문·카테고리(기획·디자인 중 1개)·태그(3~5개)
- F7 수정 요청: 초안 뒤 "더 짧게" 등 입력 → 반영한 초안을 새 카드로
- F8 저장: "이 초안 넣기"로 글쓰기 칸을 채우고, 저장은 기존 임시저장·발행 버튼

**AI 규칙** 주지 않은 내용·일반 설명으로 빈칸을 채우지 않고 "(설명 보충 필요)" 표시. 규칙을 어겨도 앱이 질문 수·카테고리·태그를 한 번 더 정리.

## 7. 디자인 요구사항 (화면·상태)
- 진입: 글쓰기 헤더 **AI 초안** 버튼 → 오른쪽 패널(PC 420px 고정, 좁은 화면은 전체를 덮음)
- 패널: 헤더(새 대화·닫기) / 대화 영역(안내, 내 메시지, 대기, 질문 묶음, 초안 카드, 오류) / 입력칸 + [그냥 써줘] [보내기]
- 초안 카드: 제목 → 요약 → 카테고리·태그 → 본문 미리보기 → [이 초안 넣기] (넣은 뒤 [다시 넣기])
- 상태: 대기 중 보내기 비활성 · 쓰던 글 교체와 새 대화는 패널 안 [취소]·[확인] · 오류는 대화 영역에 쉬운 문장으로
- 반영: 제목·본문(맨 위 "> 요약:")·카테고리·태그, 저장 상태 "AI 초안 넣음 · 아직 저장 안 됨"
- 스타일: 기존 블로그 색·글꼴·버튼 재사용, Esc 닫기, Ctrl+Enter 보내기
